### 👋 Hi there! I'm Davi

## 💻 Fullstack Software Engineer

Fullstack Software Engineer at [Longview](https://github.com/LongviewBR), where I single-handedly maintain all 4 applications of **Autigames**, a production product: a serverless backend, a web admin frontend, a mobile app, and a landing page.

- 🏗️ Architected a backend with **263 REST endpoints** organized into ~26 business domains (AWS Lambda + Serverless Framework)
- ⚡ Reduced **cold start by 20%** and **warm start by 40%** via a database connection singleton (Prisma)
- 🔐 Implemented full authentication: JWT, 2FA (TOTP), and social login (Google/Apple Sign-In)
- 🐛 Resolved an average of **24 bugs/month** (120 over the last 5 months), keeping production stable
- ✅ Wrote ~30 automated tests covering critical backend functionality
- 💳 Integrated payments (Stripe), notifications (Firebase, SES), and observability (Sentry)

### 🚀 My Current Focus

Building and operating robust, scalable fullstack products end-to-end — from serverless APIs on AWS to web and mobile clients — with a growing focus on authentication/payments security, observability, and test coverage.
